## My approach

1. Understand the current process and the people who use it.
2. Identify bottlenecks, repetitive tasks, and measurable improvement opportunities.
3. Design a workflow that fits the organisation's actual tools and constraints.
4. Build, test, document, and improve the system.
5. Track useful outcomes such as time saved, response speed, process completion, error reduction, and KPI performance.

I believe successful automation is not about adding AI everywhere. It is about solving the right operational problem reliably.
